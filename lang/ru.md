# NightAuth Telegram Bot (Self-Hosted) — Поставьте нам звезду на GitHub ⭐

Официальный бот администрирования Telegram для платформы [NightAuth](https://nightauth.org). Разработан на **TypeScript** с использованием **Telegraf v4**. Бот напрямую взаимодействует с Business API NightAuth, обеспечивая генерацию лицензий, создание учетных записей, управление HWID, администрирование нескольких приложений и динамическую поддержку 10 языков.

Официальный портал: [https://nightauth.org](https://nightauth.org)

## Возможности

- 📱 **Мультиприложения**: Управляйте несколькими приложениями NightAuth и переключайтесь между ними в одном боте Telegram.
- 🌐 **Динамическая поддержка 10 языков**: Выбирайте язык с помощью `/language`, `/lang` или через интерфейсное меню (`en`, `es`, `fr`, `de`, `it`, `pt`, `ru`, `tr`, `pl`, `zh`). Бот сохраняет предпочтения каждого пользователя.
- 🎨 **Современные Inline-клавиатуры**: Адаптивные меню с наглядными эмодзи и обновлением состояния в реальном времени.
- 📋 **Постраничная навигация**: Просматривайте списки ключей и пользователей с кнопками `◀️ Назад`, `Стр. X/Y` и `Вперед ▶️`.
- ⚡ **Пошаговые интерактивные сценарии**: Создание ключей, регистрация пользователей, продление сроков и сброс привязки HWID.
- 📊 **Диагностика в реальном времени**: Количество пользователей, действующие лицензии и статус режима обслуживания.
- 🔒 **Строгий контроль доступа**: Доступ к функциям управления разрешен только указанным числовым ID пользователей Telegram.
- 🌐 **Чистая архитектура на TypeScript**: Автономное приложение для Node.js 18+, Docker и PM2.

## Предварительные требования

1. **Node.js**: `v18.0.0` или выше.
2. **Токен бота Telegram**:
   - Откройте Telegram и начните диалог с [@BotFather](https://t.me/BotFather).
   - Отправьте команду `/newbot` и задайте имя и логин бота.
   - Скопируйте полученный HTTP API токен.
3. **Ваш ID пользователя Telegram**:
   - Напишите боту [@userinfobot](https://t.me/userinfobot) или [@rawdatabot](https://t.me/rawdatabot), чтобы узнать свой числовой ID (например, `123456789`).
4. **Ключ Business API NightAuth**:
   - Войдите в панель управления NightAuth.
   - Выберите приложение -> Перейдите в **Business Settings**.
   - Скопируйте ключ `Business API Key` (`biz_...`).

## Установка и быстрый старт

### 1. Клонирование и установка зависимостей

```bash
cd clients/bots/NightAuth-Telegram-Bot
pnpm install
```

### 2. Настройка переменных окружения

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
# Токен бота Telegram
TELEGRAM_BOT_TOKEN="123456789:ABCdefGHIjklMNOpqrsTUVwxyz"

# Эндпоинт Business API NightAuth
NIGHTAUTH_API_URL="https://nightauth.org/api/business"

# Конфигурация мультиприложений (пары Имя:Ключ через запятую)
NIGHTAUTH_APPS="MainProduct:biz_0123456789abcdef0123456789abcdef,SecondProduct:biz_fedcba9876543210fedcba9876543210"

# Язык по умолчанию (en, es, fr, de, it, pt, ru, tr, pl, zh)
DEFAULT_LANGUAGE="ru"

# Контроль доступа (числовые Telegram ID администраторов)
ADMIN_USER_IDS="123456789"
```

### 3. Запуск бота

**Режим разработки (автоперезапуск tsx):**
```bash
pnpm dev
```

**Сборка для продакшена:**
```bash
pnpm build
pnpm start
```

## Команды и взаимодействие

### Команды бота

| Команда | Описание |
| :--- | :--- |
| `/start` | Главный экран с быстрыми действиями, индикатором активного приложения и меню. |
| `/panel` | Открывает интерактивную панель управления. |
| `/apps` | Список настроенных приложений с кнопками быстрого переключения. |
| `/switchapp` | Быстрый выбор активного приложения. |
| `/stats` | Статистика приложения в реальном времени (пользователи, лицензии, статус). |
| `/language` или `/lang` | Выбор языка (`en`, `es`, `fr`, `de`, `it`, `pt`, `ru`, `tr`, `pl`, `zh`). |

### Интерактивные меню

- 🔑 **Управление лицензиями**:
  - `➕ Создать ключ`: Пошаговый мастер (дней, уровень, количество).
  - `📋 Список ключей`: Постраничный просмотр ключей, статуса и сроков.
  - `ℹ️ Инфо о ключе`: Создатель, статус активации и привязанный аккаунт.
  - `⏱️ Продлить ключ`: Добавление дней действия к лицензии.
  - `🚫 Бан / Разбан ключа`: Отзыв или восстановление лицензии.
  - `🗑️ Удалить ключ`: Безвозвратное удаление лицензии из базы данных.
- 👤 **Управление пользователями**:
  - `➕ Добавить пользователя`: Создание аккаунта с логином, паролем и ключом.
  - `📋 Список пользователей`: Постраничный просмотр зарегистрированных аккаунтов.
  - `ℹ️ Инфо о пользователе`: Просмотр HWID, уровня плана и срока подписки.
  - `🔄 Сбросить HWID`: Удаление привязки к устройству для переноса.
  - `🚫 Бан / Разбан`: Блокировка или разблокировка доступа.
  - `⏸️ Приостановить / Возобновить`: Временная приостановка входа.
  - `🗑️ Удалить пользователя`: Полное удаление аккаунта.
- ⚙️ **Параметры приложения**:
  - `⏸️ Режим обслуживания`: Мгновенная приостановка или возобновление входов клиентов.

## Развертывание в Docker

```dockerfile
FROM node:20-alpine
RUN corepack enable && corepack prepare pnpm@latest --activate
WORKDIR /app
COPY package.json pnpm-lock.yaml ./
RUN pnpm install --frozen-lockfile
COPY . .
RUN pnpm build
CMD ["node", "dist/index.js"]
```

Сборка и запуск:
```bash
docker build -t nightauth-telegram-bot .
docker run -d --name nightauth-telegram --env-file .env nightauth-telegram-bot
```
